# NewsTech Newsroom Agent

뉴스룸 종사자가 자연어로 질문하면 OpenDART 또는 KOSIS의 공식 데이터를 조회하고, 조회 조건·출처·단위·계산 근거가 포함된 검토용 브리핑을 만드는 워크숍 애플리케이션입니다.

현재 저장소는 **개발 착수용 하네스와 모의 실행 MVP**입니다. 실제 Gemini·OpenDART·KOSIS 호출은 기본적으로 꺼져 있습니다.

참가자는 질문 분석 후 대상·지표·기간·비교 기준을 확인하고 수정할 수 있습니다.
‘이 조건으로 조회’를 누르기 전에는 자료와 브리핑이 표시되지 않습니다. 미해결 조건은
한국어로 안내하며, 수정한 조건과 승인된 최종 조회 조건을 화면에서 확인할 수 있습니다.
청년 고용 실습은 가상 지역 4곳의 2020~2024년 숫자로 변화값과 순위를 계산합니다.
입력값·단위·계산 불가 이유를 함께 표시하며, 공식 통계가 아니므로 실제 취재에 사용할 수 없습니다.
기업 실적 실습은 아직 숫자가 없는 조건 확인용 모의 응답입니다. 모든 결과는 사람의 검토가 필요합니다.

승인 후에는 같은 질문의 일반 응답 예시와 근거 기반 브리핑을 나란히 비교합니다.
일반 응답은 미리 작성한 모의 문장이고, 근거 기반 응답도 실제 공공데이터 조회 전입니다.
조회 조건·자료원·단위·계산식·한계가 얼마나 드러나는지 살펴볼 수 있습니다.

결과 아래에서 승인 조건·자료 출처·계산 근거·해석 한계를 체크하며 실습 검토 진행 상태를
확인할 수 있습니다. 모든 항목을 체크해도 사실 검증 완료나 기사 사용 승인이 아닙니다.
질문·조건 변경, 다시 분석·조회, 새로고침 시 검토 표시는 초기화됩니다.
자세한 동작은 [사람 검토 흐름](docs/REVIEW_FLOW.md)에 정리했습니다.

## 구조

```text
apps/web      React + Vite 프론트엔드
apps/api      FastAPI 백엔드와 단일 에이전트 오케스트레이터
docs          제품 범위, 아키텍처, 환경 전환, 공공데이터 준비, Codex 하네스
fixtures      공식 저장 자료 준비 및 가상 계산 실습 안내
infra         Cloud Run 단일 컨테이너 배포 준비
```

개발 중에는 프론트엔드와 백엔드를 별도로 실행합니다. 스테이징에서는 프론트엔드를 빌드해 FastAPI가 함께 제공하므로 Cloud Run 서비스 하나로 운영할 수 있습니다.

## 처음 시작하기

필요 도구:

- Node.js 20
- pnpm 9
- Python 3.12
- uv
- Docker Desktop(선택)
- Google Cloud CLI(스테이징부터)

```bash
cp .env.example .env
pnpm install
cd apps/api && uv sync --dev && cd ../..
```

터미널 두 개에서 실행합니다.

```bash
make dev-api
make dev-web
```

- 프론트엔드: http://localhost:5173
- 백엔드 상태 확인: http://localhost:8000/health

또는 VS Code에서 `Terminal > Run Task > Dev: web + api`를 실행할 수 있습니다.

## 검증

```bash
make check
```

`make check`는 백엔드 테스트, 프론트엔드 동작 테스트, 타입 검사와 빌드를 실행합니다.
검토 UI만 확인하려면 `make test-web`을 실행합니다. UI 테스트는 모의 응답을 사용하고
dotenv 로딩과 실제 요청을 차단합니다.

## 환경 전환

| 단계 | 모델·인프라 소유자 | 데이터 방식 | 목적 |
|---|---|---|---|
| local | 개발자 개인 | mock 우선, 개인 키로 제한적 실험 | 기능 개발 |
| stage | 건국대학교·주최 측 | 기관 키 + 저장 자료 fallback | 부하 시험·리허설 |
| event | 건국대학교·주최 측 | 기관 키 + 모니터링 + fallback | 워크숍 운영 |

개인 키를 Git에 커밋하거나 브라우저 코드에 넣지 않습니다. 자세한 내용은 [환경 전환 문서](docs/ENVIRONMENTS.md)를 확인하십시오.

## 현재 범위

- 포함: 단일 오케스트레이터, 조건 편집·승인, 응답 비교, 가상 수치의 결정론적 계산·순위·누락값 검증, 근거 패널, 실습 검토 체크리스트·진행 상태, 공급자 어댑터 골격, Cloud Run 준비
- 후속 구현: 조건별 결과 비교, 실제 원자료 조회·정규화·검증
- 제외: 멀티에이전트, 기사 자동 발행, CMS 연동, 모든 공공데이터 자유 질의, 행사 이후 상시 운영

제품 범위는 [제품 개요](docs/PRODUCT_BRIEF.md)에 정리되어 있습니다.
가상 숫자로 비교 기준과 오류를 체험하는 방법은 [계산 실습 안내](fixtures/synthetic/README.md)를 참고하십시오.
