# 제품 개요

## 한 문장 목표

뉴스룸 종사자가 범용 챗봇 답변과 공식 공공데이터에 근거한 검토 가능한 에이전트 작업의 차이를 직접 경험하도록 합니다.

## 대상

- 기자
- 데스크
- 디지털 전략 담당자
- 서비스 기획자
- 뉴스룸 기술·데이터 담당자

## 핵심 경험

1. 자연어 취재 질문을 입력합니다.
2. 에이전트가 OpenDART 또는 KOSIS를 선택한 이유와 해석한 조건을 보여줍니다.
3. 참가자가 지표·기간·단위·비교 기준을 확인하고 수정합니다.
4. 공식 데이터를 조회하고 결정론적 코드로 계산합니다.
5. 출처·원자료·계산식·한계가 포함된 브리핑을 확인합니다.
6. 참가자가 사용 가능 여부를 검토하고 추가 취재 질문을 작성합니다.

## 워크숍의 핵심 대비

실습은 두 부분으로 구성합니다. **1부**는 기존 안내형 질문으로 조건 승인·자료와 계산·사람
검토 절차를 익힙니다. **2부**는 자기 취재 질문을 입력하고 에이전트가 제안한 조사 계획을
자연어 또는 폼으로 수정·승인한 뒤, 조회 근거에 연결된 Gemini 브리핑을 검토합니다.
OpenDART는 상장회사 한 곳의 연간 연결 매출액·영업이익, KOSIS는 검증된 청년 고용률
카탈로그를 사용합니다. 회사·보고서 존재 확인은 계획 단계에 허용하지만 수치는 승인 후
조회합니다. [2부 계약과 실습 안내](RESEARCH_WORKSHOP.md)를 참고합니다.

단순히 “답을 생성하는 AI”를 보여주지 않습니다. 다음 차이를 보여줍니다.

- 일반 응답과 공식 자료 조회 응답
- 암묵적인 가정과 확인 가능한 조회 조건
- 그럴듯한 문장과 재현 가능한 계산
- 자동 생성과 사람의 승인

## MVP 성공 기준

- 두 개의 사전 검증 질문이 끝까지 작동합니다.
- 참가자가 조건을 한 번 이상 바꾸고 결과 차이를 확인할 수 있습니다.
- 출처·기간·단위·계산식·주의사항이 화면에 표시됩니다.
- 오류나 모호성 때문에 에이전트가 멈추는 장면이 한 번 이상 있습니다.
- 30명 동시 사용 부하 시험과 저장 자료 fallback 리허설을 통과합니다.

## MVP 제외 범위

- 기사 자동 작성·발행
- CMS 연동
- 임의 웹 검색
- 모든 기업·통계표의 완전 자유 질의
- 멀티에이전트
- 행사 이후 상시 서비스 운영
