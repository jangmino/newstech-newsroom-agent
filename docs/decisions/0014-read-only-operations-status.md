# ADR 0014: 외부 호출 없는 읽기 전용 실습 운영 상태

- 상태: 구현 완료
- 날짜: 2026-09-16

## 결정

M3의 운영 화면을 `GET /api/v1/operations`와 접을 수 있는 화면 패널로 한정한다.
기존 공유 접근코드를 동일하게 검사하며 별도 관리자 역할·설정 변경 기능을 만들지 않는다.

- Gemini·OpenDART·KOSIS는 활성화 조건과 필수 설정의 존재만 검사한다. 설정상 허용,
  비활성화, 필수 설정 부족을 구분하며 실제 연결·키 유효성·잔여 할당량은 확인하지 않는다.
- 공식 저장 자료는 기존 패키지 로더로 파일·해시·정규화 가능 여부를 확인한다. 출처와
  원래 조회 시각·범위만 반환하며 숫자·근거·브리핑은 조건 승인 뒤 기존 실행 API로 제공한다.
- 캐시 TTL·자료원별 최대 항목 수와 Gemini/공공자료 호출 한도 설정을 보여 준다.
  모두 프로세스 내부 범위이며 실시간 사용량·행사 전체 한도·비용을 뜻하지 않는다.
- 설정 전체를 직렬화하지 않는다. 키·접근코드·프로젝트/파일 경로·환경 원문·공급자 오류를
  반환하거나 로그에 기록하지 않는다. 응답 필드는 명시한 공개 상태 모델로 제한한다.
- 패널을 열거나 ‘상태 다시 확인’을 누를 때만 조회한다. 자동 갱신·외부 공급자 호출·
  캐시/한도 초기화는 없다. 닫기·나가기는 요청을 취소하고 늦은 응답을 무시한다.
  일반 상태 오류는 실습 입력·결과·검토를 유지하고 접근 오류는 기존 입장 정책을 따른다.

## 제외 범위

운영 제어, 새 인증·DB, 로그 조회·집계, 연결 시험, 실제 API 호출, 기관 자원 생성·
Secret Manager 설정·Cloud Run 배포·과금 활성화·부하 시험은 이번 단위에서 제외한다.
