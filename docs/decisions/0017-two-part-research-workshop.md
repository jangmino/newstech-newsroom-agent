# ADR 0017: 1부 안내형 실습과 2부 자유 질문 조사·브리핑

- 상태: 사용자 승인, 구현 진행
- 날짜: 2026-09-17

## 결정과 승인 범위

현재 안내형 흐름을 **1부 실습**으로 보존한다. **2부 실습**에는 (1) Gemini 근거 기반
브리핑, (2) OpenDART 회사 검색·연간 매출액/영업이익·기간 확장, (3) OpenDART 또는
KOSIS를 선택하는 자유 질문 조사 계획·자연어 수정·사람 승인 흐름을 추가한다.
사용자가 세 개발 범위를 함께 승인하고 구현 세부 결정을 위임했다. 각 내부 단위에서
재승인을 요청하지 않으며 검증과 Git 체크포인트는 분리한다.

1부의 기존 질문·API 기본값·mock/snapshot·검토 흐름과 `/api/v1/analyze` 호환성을 유지한다.
2부는 별도 조사 계약을 사용하며 단일 오케스트레이터와 기존 공급자 어댑터를 재사용한다.
DB·계정 인증·멀티에이전트·임의 웹 검색·자동 기사 작성/발행·복수 자료원 결합은 추가하지 않는다.

## 조사 범위와 승인 경계

- Gemini는 준비된 도구 목록에서 자료원과 의미 조건을 선택한다. 회사 코드·통계표 코드·
  계정 ID·호출 URL을 생성하거나 실행하지 않는다. 서버가 공식 목록과 허용 계약으로 결정한다.
- 승인 전 OpenDART 회사 목록·사업보고서 목록을 확인할 수 있다. 재무 수치 조회는 승인 후다.
  회사 식별과 제공 연도 확인은 1부의 ‘계획 단계 외부 자료 호출 없음’에 대한 2부 전용 예외다.
- OpenDART는 공식 회사 목록의 상장회사 한 곳, 12월 결산 연간 연결 재무제표, 매출액과
  영업이익, 최대 5개 연도를 다룬다. 공식 보고서 존재와 표준 재무 계정 제공은 별개이며
  계정 누락·중복·다른 통화는 오류로 알린다. 영업손실은 음수로 보존하고 기준값이 0 이하이면
  증감률을 만들지 않는다. 연간 값과 비교 방법은 코드가 계산한다.
- KOSIS는 검증된 고용률 통계표와 15~29세·2020~2024년 범위를 카탈로그로 제공한다.
  시도별·수도권·비수도권·개별 시도 질문을 지원한다. 모든 통계표의 자유 검색은 제외한다.
- 모호한 조건은 명시적 제안 또는 확인 질문으로 표시한다. 지원하지 않는 명시 조건을
  자동 대체하지 않는다. 계획 편집·질문/모드 변경은 결과와 검토를 초기화하고 재승인한다.
- mock은 외부 호출 없이 같은 2부 흐름을 연습하며 가상 회사 자료와 가상 수치를 명확히 표시한다.
  기존 공식 snapshot을 새 기업·지표의 자료로 재사용하지 않는다.

## 근거 기반 브리핑

Gemini에는 승인 조건·정규화된 근거·코드 계산·출처·한계만 전달한다. 수치는 근거 참조를 통해
렌더링하고 존재하지 않는 참조·임의 숫자·외부 링크를 거부한다. 근거 ID를 화면의 원자료와
연결한다. 이는 문장 의미나 인과관계의 완전 검증이 아니며 사람 검토 필요 상태를 유지한다.
작성 방식과 모델을 표시하고, 실패한 생성 결과를 정상 브리핑처럼 표시하지 않는다.
조회된 근거는 보존하여 재승인 후 다시 시도할 수 있게 한다. 자동 재시도·숨은 대체는 없다.

## 호출량과 검증

계획/자연어 수정마다 Gemini 최대 1회, 승인 실행마다 브리핑 최대 1회다. 기존 Gemini 한도를
공유한다. OpenDART 최초 회사 목록 1회(프로세스 캐시), 회사별 보고서 목록 1회(캐시), 승인 후
선택 연도당 재무제표 1회(최대 5회)다. KOSIS 승인 실행은 최대 1회다. 공공자료의 기존
호출 제한·캐시·로그 비밀정보 보호를 재사용한다. 30명 live 부하는 2부 완료 후 별도로 산정한다.

자동 테스트는 환경 파일과 외부 네트워크를 차단한다. 승인 전 수치/브리핑 호출 없음, 회사
모호성·누락 자료·음수/0 계산·모델 오류·인용 검증·조건 수정/늦은 응답/검토 초기화를 검사한다.
개인 stage의 기존 배포·소규모 live 검증 승인을 유지하되 자원·결제·접근 범위를 넓히지 않는다.
이번 수동 확인은 Gemini 최대 10회, OpenDART 최대 16회, KOSIS 최대 2회로 제한하고 기록한다.
기관 계정 요청·이전은 마지막 인계 단계로 유지한다.
