# ADR 0021 — 2부의 다섯 취재 분석 시나리오

- 결정일: 2026-10-05
- 상태: 사용자 승인, 구현·원문 검증 완료; 2026-10-06 main 병합·개인 stage 공개.
  소규모 검증·오류 복구 확인, 30명 실제 부하·현장 운영 검증 별도.
- 작업 브랜치: `feature/workshop-investigation-scenarios`

## 승인 범위

A 출생 회복의 지역 격차, B 청년 순유출과 목적지, C 물가 상승률과 근사 기여도,
D 임원·직원 보수 비교, E NAVER·카카오 2021~2025 매출 구조 변화를 추가한다.
연구원 원안의 시장 전체 CB 추적과 반도체 실적·산업지수 결합은 이번 범위에서 제외한다.
동일 공급자의 여러 공식 표·보고서를 결합하는 분석과 두 회사의 재무 비교를 허용한다.
임의 통계표 탐색·임의 웹 검색·기사 작성/발행·DB·인증·멀티에이전트는 추가하지 않는다.

2부는 자연어 확인 → 읽을 수 있는 조사 계획 → 명시적 승인 → 조회/계산 → 상세 브리핑 →
사람 검토로 진행한다. API 매개변수 폼을 필수 절차로 두지 않는다. 조건 수정은 재계획과
재승인을 요구하며 결과·검토를 무효화한다. 1부 및 기존 API 회귀 계약은 유지한다.

## 자료와 해석

자료 수집·계산·순위·검증은 서버가 수행하고 Gemini는 질문 해석과 근거 설명을 맡는다.
숫자 슬롯·근거 인용 검증을 유지한다. 브리핑은 결론, 핵심 발견, 비교표, 예외, 한계,
후속 취재를 연결하며 자료로 확인하지 못한 원인을 생성하지 않는다.

- A: 전년 동월 대비와 전월 대비를 구분한다. 비교 구간 앞 12개월을 확보한다.
  확인 기간 밖의 '역대' 기록을 주장하지 않으며 결측·잠정·행정구역 경계를 표시한다.
- B: 목적지는 OD 표로 확인하고 순이동만으로 추론하지 않는다. 20~34세·같은 연령 인구
  분모를 사용한다. 지역 경계가 다른 구간을 이름 치환만으로 결합하지 않는다.
- C: 말단 품목만 순위화한다. 적용 기간의 공식 가중치를 사용하고 근사 기여도를 공식
  기여도로 표현하지 않는다. 지수/가중치 기준 차이 및 총지수 대조 결과를 공개한다.
- D: 기본 두 회사·2025 연간. CEO 직위, 공시 대상, 평균급여 분모와 보수 구성 확인.
  미공시를 0으로 처리하지 않는다. 미행사 보상을 보수에 합산하거나 반기를 연간화하지 않는다.
- E: 공식 사업보고서 원문과 연결 재무를 준비한다. 부문별 매출 구성과 증가액, 영업이익률을
  계산하며 서로 다른 사업 분류를 강제로 동일시하지 않는다. 자료·접수번호·원문 위치·단위·
  정정/분류 변경·수집 시점·검증 방식의 목록을 `INVESTIGATION_DATA.md`에 남긴다.

공식 저장 자료는 실제 수집한 원자료만 포함하고 출처·버전을 고정한다. 실시간 실패 시
조용히 대체하지 않는다. 저장 자료 재사용도 참가자 승인 이후에 수행한다.

## 호출 예산과 변경 경계

개발 수동 검증 초기 상한은 공공 API 200회, Gemini 10회다. 최종 검토에서 E의 시작 연도 비중과 B의 코드 계산 순위가 브리핑에
반영되는지 확인하기 위해 브리핑 2회를 추가해 한도를 12회로 조정했다. 마지막 연도에 치우친 E 요약을 보완하고 시작·종료 연도
대비를 한 번 더 확인하여 실제 최종 호출은 13회다(계획 5, 브리핑 8). 호출·오류를 비밀정보 없이
기록하며 자동 테스트는 모의 전송만 사용한다. 같은 표/보고서 조회 공유와 계산 재사용을
우선하며 stage의 RPM·동시성·결제·배포 구성은 이번 개발 중 변경하지 않는다.
개발 이후 실제 호출 수, 토큰, 지연, 오류와 30명 혼합 사용을 근거로 사용자와 재검토한다.
검토 목록은 `INVESTIGATION_FOLLOWUPS.md`에 유지한다. 공개 배포는 별도 요청을 따른다.

## 완료 증거

기능, 공식 수치·원문 대조, 오류 대응, 행사 운영을 구분해 `INVESTIGATION_VALIDATION.md`에
기록한다. 미검증 범위를 완료로 표시하지 않는다. `make check`, `git diff --check`, 비밀정보
변경 검사를 수행한다. 실제 제공 범위가 핵심 질문을 충족하지 못하거나 일정에 영향을 주면
그 부분의 근거와 대안을 제시하고 사용자와 논의한다.

## 구현 시 확정한 제공 경계

D/E는 원문 대조한 공식 저장 원자료만 제공한다. 실시간 재조회처럼 표시하지 않으며
참가자가 이를 확인하고 승인해야 한다. A~C는 live 또는 명시적 archive를 선택한다.
B는 전국 시도와 선택 시도 목적지를 제공하되 시군 상세는 경북만 검증했다.
C는 2025-09/2026-09 두 시점과 검증된 가중치만 제공한다. 상세 범위·공식 원문
접수번호·재현 방법은 [자료 구성](../INVESTIGATION_DATA.md)에 기록했다.
새 다섯 사례의 Gemini 장애용 사전 생성 결과는 별도 후속 운영 검토 항목이다.
