# ADR 0007: KOSIS 청년 고용의 첫 실제 자료 계약

- 상태: 채택 — 자료 계약·오프라인 검증 준비, 참가자 live 연결 전
- 날짜: 2026-09-16

## 배경

기존 청년 고용 mock은 가상 지역, 15~29세/15~34세, 고용률/취업자 수를 제공합니다.
공식 통계의 코드와 단위를 확인하지 않고 mock 선택지를 그대로 실제 조회에 적용하면
다른 연령이나 지표를 가져올 수 있습니다. 사용자가 요청한 다음 단위는 이 대응 관계의
확인입니다. 기존 공급자·질문을 유지하고 실제 연결의 지원 범위를 명시합니다.

## 결정

- 경제활동인구조사의 `101 / DT_1DA7015S`(행정구역(시도)/연령별 경제활동인구)를 사용합니다.
- 첫 범위는 연령 분류 `G / 75`(15~29세), 항목 `T90`(고용률), 단위 `%`입니다.
  2020~2024년 중 시작·종료 연도를 포함한 연간 자료만 취급합니다.
- 시도 분류 `A`의 17개 코드를 명시합니다. 전국 집계 `00`과 추가 집계 `12`를 제외합니다.
  수도권은 서울·인천·경기의 시도별 비교, 비수도권은 나머지 14개 시도의 비교입니다.
  이들 지역의 비율을 평균내어 권역 전체 고용률을 만들지 않습니다.
- 이 표의 확인된 항목에는 취업자 수가 없고, 연령 분류에는 15~34세가 없습니다.
  다른 지표 대입·연령 비율 평균·고용률에서 취업자 수 역산을 하지 않습니다.
  mock 선택지는 유지하며 후속 live UI에서는 지원 범위를 알리고 재확인하게 합니다.
- 연간 요청은 `prdSe=Y`이지만 실제 자료 응답은 `PRD_SE=A`였습니다.
  요청 코드와 응답 코드를 분리해 검사합니다.
- 순수 정규화 함수가 표·지역·연령·항목·주기·연도·단위와 전체 셀을 검증합니다.
  누락 행, 중복 행, 비수치·통계 부호, 범위 밖 값은 중단하며 0이나 추정치로 바꾸지 않습니다.
- 공개 API 발췌를 오프라인 테스트에만 사용합니다. 조회 시각과 최종수정일을 구분하고
  실제 호출 시각을 새로 붙인 snapshot이나 실시간 fallback으로 제공하지 않습니다.
- 이번 단위에는 네트워크 어댑터·공개 API·프론트엔드 계약 변경이 없습니다.
  KOSIS 참가자 흐름은 계속 mock이고, 기존 OpenDART live 흐름을 유지합니다.

## 영향과 남은 일

공식 값의 형식과 차원을 확인할 수 있지만 API 성공은 통계 해석·기사 사용 승인이 아닙니다.
표본오차, 공표 반올림, 개정, 지역 경계 변경과 비교 가능성은 사람 검토에 남깁니다.
정규화는 모든 시점이 동일한 경계라는 보증을 하지 않습니다.

다음 단위는 별도 KOSIS 활성화 설정과 안전한 전송, 승인 후 조회·계산·근거·브리핑·
검토 UI 연결입니다. 기존 검색 골격을 그대로 운영 경로에 사용하지 않습니다.
Gemini 추가 호출, DB, 인증, M3의 캐시·fallback·배포는 추가하지 않습니다.

공식 링크·실제 확인 기록·정확한 코드 목록은 [KOSIS 계약](../KOSIS_EMPLOYMENT.md)에 있습니다.
