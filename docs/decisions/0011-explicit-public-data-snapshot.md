# ADR 0011: 참가자가 선택·재승인하는 공식 저장 자료

- 상태: 구현 완료
- 날짜: 2026-09-16

## 결정

M3의 장애 대응에 기존 OpenDART/KOSIS 공개 발췌를 공식 저장 자료로 사용한다.
ADR 0007·0008에서 테스트 전용이던 사용 범위를 이번 결정으로 확장한다. 숫자·원래 조회
시각·출처는 변경하지 않는다. 새 공급자·실습 질문·DB·인증·외부 호출·배포를 추가하지 않는다.

- `/plan`과 `/execute`에 `mode=snapshot`을 추가한다. `FALLBACK_SNAPSHOT_ENABLED`로
  허용하며 live 활성화·키·캐시·HTTP 호출 한도와 독립적이다. 기본 mock과 `/analyze`는 유지한다.
- 참가자는 처음부터 ‘공식 저장 자료’를 선택하거나 실제 조회 오류 뒤 명시적으로 전환한다.
  전환만으로 실행하지 않는다. 출처·지원 범위·원래 확보 시각·검증 한계를 읽고 다시 승인한다.
- 오류 뒤 전환은 `/plan`에 기존 편집 `conditions`를 보낼 수 있다. snapshot의 모의 규칙
  방식에서만 허용하며 외부 해석을 다시 하지 않는다. 미지원 조건은 안내 후 비워 재선택하게 한다.
  직접 snapshot 질문 분석에서는 기존 해석 방식 선택을 유지한다. Gemini 선택은 별도의 명시적 호출이다.
- 계획은 숫자·브리핑 없이 `snapshot` 메타데이터와 지원 조건만 반환한다. 실행 요청은
  확인한 `snapshot_id`와 `approved=true`가 필요하며 저장 자료 버전이 달라지면 재확인을 요구한다.
- 실행 때 조건·자료원·버전·자료 무결성을 다시 검사한다. live와 같은 정규화·결정론적
  계산을 사용하며 결과에는 `data_mode=snapshot`, 원래 시각과 저장 자료 메타데이터를 남긴다.
- 실제 조회 오류를 snapshot 성공으로 바꾸지 않는다. 만료 캐시·부분 응답·가상 수치를
  저장 자료로 대체하지 않는다. 파일 누락·변조·미지원 조건은 안전한 한국어 오류로 중단한다.
- 일반 응답은 기존 고정 mock 예시다. 저장 자료 기반 결과는 최신 자료·기사 사용 승인이
  아니며 재승인마다 사람 검토는 초기화된다. 다른 자료 모드·저장 버전끼리 조건 비교하지 않는다.

## 저장과 배포

두 JSON 발췌를 `newsroom_agent/snapshot_data/`로 옮겨 백엔드 wheel/sdist에 포함한다.
테스트도 같은 원본을 읽으며 이중 복사본을 만들지 않는다. 허용된 파일·버전·SHA-256을
코드로 고정하고 임의 경로·URL·참가자가 올린 자료를 읽지 않는다. 업데이트는 새 버전과
검증 기록을 포함한 코드 배포로 한다. 런타임 자동 저장·갱신은 없다.

KOSIS는 15~29세 연간 고용률 17개 시도 × 2020~2024년, OpenDART는 삼성전자
2022·2024년 연결 매출액만 지원한다. 확보 이후 개정·정정은 반영되지 않는다.
사람의 원문·해석 검토와 행사 장애 리허설은 별도로 남는다.
