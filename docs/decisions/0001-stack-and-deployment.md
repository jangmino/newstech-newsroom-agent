# ADR 0001: React, FastAPI, 단일 Cloud Run 배포

- 상태: 승인
- 날짜: 2026-09-09

## 결정

프론트엔드는 React/Vite/TypeScript, 백엔드는 FastAPI/Python 3.12를 사용합니다. 로컬에서는 두 프로세스로 개발하고, stage와 event에서는 프론트엔드 정적 결과를 FastAPI가 제공하는 단일 Cloud Run 컨테이너로 배포합니다.

## 이유

- 프론트엔드와 데이터·AI 로직의 책임을 구분할 수 있습니다.
- Python 생태계로 공공데이터 정규화와 검증을 다루기 쉽습니다.
- 행사 당일 서비스 수와 네트워크 경로를 줄여 운영 부담을 낮춥니다.
- 필요할 경우 이후 프론트엔드와 API를 분리할 수 있습니다.

## 결과

- 빌드 과정은 두 단계이지만 배포 대상은 하나입니다.
- 백엔드 장애가 전체 화면에 영향을 주므로 snapshot fallback이 필수입니다.
