# ADR 0003: 가상 수치 자료로 계산·검증 기초 구현

- 상태: 승인된 다음 단계의 구현 결정
- 날짜: 2026-09-16

## 범위

기존 청년 고용 질문 하나에 계산을 추가합니다. 새 공식 자료원이나 실습 질문을
추가하지 않습니다. OpenDART 흐름은 조건 확인용 mock을 유지합니다.

KOSIS 연결을 준비하는 실습에는 직접 만든 가상 지역 A~D와 2020~2024년 숫자를 씁니다.
A·B는 수도권 예시, C·D는 비수도권 예시로만 분류합니다. ‘전국 시·도’는 이 가상 지역
4곳을 모두 고르는 기존 UI 선택값이며, 실제 전국 통계를 뜻하지 않습니다.
고용률(%)·취업자 수(천 명), 15-29세·15-34세 조건별 독립 시계열을 준비합니다.
두 연령 집단의 수치를 합산하거나 이 자료에서 실제 사회 현상을 추론하지 않습니다.

가상 자료는 백엔드 패키지의 `providers/mock_employment.py`에 버전과 함께 둡니다.
공식 응답을 보관하는 `fixtures/public-data`와 구분합니다. 외부 조회·키·DB는 사용하지
않습니다. 모든 결과는 `mock`, `synthetic`, ‘공식 통계 아님’, ‘사람 검토 필요’를 표시합니다.

## 계산 규칙

- 승인 기간의 시작·종료 연도만 비교합니다. 연간 추세나 회귀분석은 하지 않습니다.
- 증감 폭은 종료 값 - 시작 값입니다. 고용률은 %p, 취업자 수는 천 명입니다.
- 증감률은 (종료 값 - 시작 값) / 시작 값 × 100이며 단위는 %입니다.
- 십진 문자열을 Decimal로 계산하고 표시값만 소수 둘째 자리까지 남겨 반올림합니다
  (`ROUND_HALF_UP`, 소수 2자리 유지). 순위는 반올림 전 값의 내림차순입니다.
- 동률은 같은 순위, 다음 순위는 건너뛰는 방식입니다(1, 1, 3). 동률 내 표시 순서는
  가상 지역명 순서로 고정합니다. 표시값이 같아도 반올림 전 값이 다르면 순위는 다릅니다.
- 음수 변화도 그대로 표시합니다. 순위가 높다는 이유로 고용이 개선됐다고 단정하지 않습니다.
- 시작·종료 값 누락과 증감률의 0 기준값은 계산·순위에서 제외하되 행과 이유를 표시합니다.
  계산 가능한 일부 지역만으로 순위를 낸 사실을 경고하며, 모두 계산 불가면 1위를 만들지 않습니다.
- 단위 불일치·비정상 숫자·중복 지역·고용률 범위 위반은 자료 오류로 전체 계산을 중단합니다.
- 지원하지 않는 기간은 422로 거부합니다. 자동으로 다른 연도나 저장 결과를 선택하지 않습니다.

## 계약과 표시

`/plan`은 지원 연도만 추가로 안내하고 승인 전 숫자를 반환하지 않습니다.
`/execute`의 `calculation`에 계산 상태·입력값·변화값·순위·경고를 구조화합니다.
`evidence.raw_values`에는 선택된 시작·종료 원자료와 단위를 제공합니다.
조회 조건은 계속 승인 값과 일치하며, 일반 응답 예시와 기존 `/analyze` 동작은 유지합니다.

다음 단계의 실제 원자료 정규화·단위 변환·공식 fixture 검증은 별도로 수행합니다.
