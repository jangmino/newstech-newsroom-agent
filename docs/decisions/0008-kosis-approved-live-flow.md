# ADR 0008: 승인 후 KOSIS 실제 청년 고용 비교

- 상태: 구현 완료
- 날짜: 2026-09-16

사용자가 다음 단위를 요청하여 ADR 0007의 검증된 자료 계약을 참가자 흐름에 연결합니다.
새 통계표·핵심 질문·공급자를 추가하지 않습니다.

- 기존 `mode=mock|live`를 유지합니다. live는 질문에 따라 OpenDART 또는 KOSIS 한 곳을
  사용하며 공급자별 활성화·키 설정을 따로 검사합니다. 알 수 없는 질문은 조건 확인으로
  멈추고, 질문과 승인 자료원이 다르면 조회하지 않습니다.
- KOSIS에는 `KOSIS_ENABLED=false` 기본 설정을 추가합니다. 실제 사용은 전역 live,
  공공자료 live 허용, KOSIS 활성화와 백엔드 키가 모두 있어야 합니다.
- `/plan`에는 자료 조회가 없습니다. `/execute`는 명시적 승인과 조건 재검증 뒤에만
  고정 통계표의 연간 15~29세 고용률을 한 번 요청합니다. 최대 17개 시도 × 5년 = 85개 셀입니다.
- 재시도·리다이렉트·환경 프록시·자동 mock/snapshot 대체를 사용하지 않습니다.
  타임아웃·응답 크기·JSON 형식·차원·단위·누락·중복을 검사하고 전체 실패로 중단합니다.
  키가 포함된 URL, 공급자 원문 오류, 로그를 참가자나 저장소에 노출하지 않습니다.
- 기존 `calculation`의 `data_origin`에 `kosis`를 추가합니다. Decimal 순위 계산을 재사용하되
  mock 전용 문구를 구분합니다. 시작값 0의 증감률은 순위에서 제외하고 이유를 표시합니다.
- 근거에는 승인 조건, 공식 통계표 링크, 조회 인자, 시도·연령·항목 코드, 연간 값·단위,
  조회 시각과 최종수정일을 남깁니다. 중간 연도도 근거에서 확인할 수 있지만 순위는 승인한
  시작·종료 값의 변화로 계산합니다. 권역 비율 평균이나 연령 환산은 하지 않습니다.
- 화면은 15~34세·취업자 수 미지원을 안내하고 자동 대체하지 않습니다. 조건·질문·자료 모드
  변경은 결과·검토를 초기화합니다. 일반 응답은 고정 모의 예시이고 사람 검토 필요 상태를 유지합니다.
- `/analyze`는 기존 mock 전용 호환 경로로 남습니다. Gemini 해석은 독립적이며 승인 후
  다시 호출하거나 브리핑을 모델로 작성하지 않습니다. DB·인증·M3 운영 기능은 추가하지 않습니다.

자동 테스트는 공개 fixture와 모의 전송만 사용합니다. 구현 후 소규모 실제 확인은 최대 4회로
제한하고 공식 원표·공표 단위·계산을 확인합니다. API 성공이나 체크 완료를 기사 사용 승인으로
표현하지 않습니다. 로컬 활성화는 사용자가 허용한 `.env` 수정 범위에서 수행하며 키는 출력하지 않습니다.

실제 승인 조회 2회와 공식 표의 34개 시작·종료 값 대조를 완료했습니다.
지원 범위·계약은 [자료 문서](../KOSIS_EMPLOYMENT.md), 절차·결과·한계는
[실제 확인 기록](../KOSIS_SMOKE_TEST.md)에 남깁니다. 행사 운영 기능은 후속 M3 범위입니다.
