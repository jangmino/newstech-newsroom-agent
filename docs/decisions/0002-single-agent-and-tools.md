# ADR 0002: 단일 조정 에이전트와 명시적 도구

- 상태: 승인
- 날짜: 2026-09-09

## 결정

하나의 조정 에이전트가 질문을 구조화하고 OpenDART 또는 KOSIS 도구를 선택합니다. 각 기능을 별도 에이전트로 만들지 않습니다. 계산과 검증은 결정론적 코드로 수행합니다.

## 이유

- 두 개의 고정된 실습 질문에는 멀티에이전트가 필요하지 않습니다.
- 실행 경로와 오류 원인을 참가자와 운영자가 이해하기 쉽습니다.
- 지연, 비용, 요청 수와 디버깅 부담을 줄입니다.

## 재검토 조건

서로 독립적인 장기 작업이 실제로 필요하고, 단일 오케스트레이터로 해결할 수 없다는 측정 가능한 근거가 생길 때만 재검토합니다.
