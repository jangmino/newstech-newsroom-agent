# ADR 0006: 승인 후 OpenDART 실제 매출액 비교

- 상태: 사용자 승인 범위의 구현 결정
- 날짜: 2026-09-16

사용자가 OpenDART 완성을 요청하여 ADR 0005의 내부 어댑터를 참가자 흐름에 연결합니다.
실제 조회와 원문 대조, 공개 fixture, 계산, UI, 테스트·문서를 한 기능 범위로 진행합니다.
새 자료원이나 핵심 질문은 추가하지 않습니다.

`/plan`과 `/execute`는 `mode=mock|live`를 받으며 기본값은 mock입니다. live는 삼성전자
2022·2024년 연간 연결 매출액만 지원하고, 비교 기준은 증감 폭/률입니다. 제공 가능한
전체 연도와 검증한 실습 범위를 구분합니다. KOSIS, 영업이익, 별도, 분기는 live에서
허용하지 않습니다. 지원하지 않는 해석 조건은 비우고 참가자가 명시적으로 수정합니다.

전역 `LIVE_API_ENABLED`, `PUBLIC_DATA_MODE=live`, `OPENDART_ENABLED`를 모두 검사합니다.
계획은 자료를 조회하지 않습니다. 승인과 조건 재검증 뒤 두 연도를 순차 요청하며,
자동 재시도·부분 성공·mock/snapshot 자동 대체는 없습니다. 질문 해석 방식은 독립적이며
실행 시 Gemini를 호출하지 않습니다. `/analyze`는 이전 mock 계약을 유지합니다.

`financial_calculation`을 별도 추가하여 고용 순위용 `calculation` 계약을 유지합니다.
원 단위 금액과 증감 폭은 정확한 정수 문자열, 증감률은 Decimal로 계산 후 소수 둘째
자리 반올림입니다. 시작값 0은 증감률 계산 불가로 표시합니다. 공시 링크·접수번호·
연도별 조회 시각·표준 계정·공개 요청 조건을 제공하고 사람 검토 필요 상태를 유지합니다.
브리핑은 검증된 입력값과 결정론적 계산으로 구성한 문장이며 LLM 작성은 포함하지 않습니다.

UI에서 자료 모드를 직접 선택하고 모드 변경 시 조건·결과·비교·검토를 초기화합니다.
일반 응답은 여전히 고정 모의 예시이며 실제 근거 기반 결과와 구분합니다.
공개 fixture는 오프라인 회귀 테스트용 정규화 발췌이며 실제 응답 전체나 운영 fallback이
아닙니다. DB·인증·배포·KOSIS 연결·M3 운영 기능은 추가하지 않습니다.
