# ADR 0005: 삼성전자 연간 연결 매출액 어댑터

- 상태: 승인된 다음 최소 단위의 구현 결정
- 날짜: 2026-09-16

후속: 실제 원문 대조와 참가자 연결은 [ADR 0006](0006-opendart-approved-live-flow.md)에서
진행했습니다. 아래 공개 API 미연결 설명은 이 결정 당시의 범위입니다.

## 범위와 계약

OpenDART 단일회사 전체 재무제표 API를 사용하는 내부 어댑터를 구현합니다.
삼성전자 고유번호 `00126380`, 사업보고서 `11011`, 연결 `CFS`, 매출액만 다룹니다.
자료원 추가가 아닌 기존 기업 실적 시나리오의 첫 공식 조회 계약입니다.
공개 `/plan`·`/execute`·`/analyze`와 프론트엔드 타입은 변경하지 않습니다.
이번 단위에서는 실제 공공데이터 호출이나 화면의 live 전환을 하지 않습니다.

시작·종료 연도에 각각 한 번씩, 최대 두 번 순차 요청합니다. 당해 연도 사업보고서를
가정하지 않도록 2015년부터 직전 연도까지의 서로 다른 두 연도만 받습니다.
일반 API의 제공 시작 연도와 실제 특정 연도의 계정 존재 여부는 구분합니다.
첫 요청이 실패하면 두 번째 요청을 하지 않으며 부분 결과·자동 재시도·fallback은 없습니다.

각 응답의 회사·사업연도·보고서가 요청과 일치하는지 확인합니다. 손익/포괄손익계산서에서
허용한 표준 매출 계정 ID(`ifrs-full_Revenue`, `ifrs_Revenue`)가 하나여야 합니다.
회사별 임의 계정명 추정, 계정 합산, 여러 후보 중 첫 행 선택은 하지 않습니다.
서로 다른 연도는 각 사업보고서의 당기금액을 사용하며 전기·누적금액으로 대체하지 않습니다.

정규화 결과에는 원래 금액 문자열과 정확한 정수 문자열, KRW/원, 계정 식별자,
접수번호·원문 링크·조회 시각·키를 제외한 요청 조건을 남깁니다. 빈 값·대시를 0으로
바꾸지 않으며 음수·비정상 숫자·다른 통화·중복 매출 계정은 오류로 중단합니다.
이 단계에서는 증감 계산이나 기사 사용 승인 상태를 만들지 않습니다.

## 오류와 비밀정보

인증·요청 제한·자료 없음·타임아웃·공급자 장애·응답 계약 오류를 내부 오류 코드와
고정 한국어 안내로 변환합니다. 원래 공급자 메시지와 인증키가 포함된 URL은 노출하지
않습니다. HTTP 타임아웃을 적용하고 리다이렉트와 환경 프록시를 사용하지 않습니다.
OpenDART 요청 처리 중에는 해당 작업의 HTTP 라이브러리 로그를 억제하여 URL의 키와
반사된 응답 헤더를 남기지 않습니다. 다른 요청의 로그 수준은 바꾸지 않습니다.

어댑터는 기본 비활성화이며 생성 시 명시적으로 활성화해야 합니다. 서버 라우트에서는
아직 생성하지 않습니다. 실제 연결 단계에서 전역 live 설정과 공급자별 활성화, 승인
조건을 함께 검사해야 합니다. Gemini 활성화만으로 OpenDART를 호출하지 않습니다.

## 검증과 다음 단계

직접 만든 작은 응답과 `httpx.MockTransport`로 계약·정규화·오류·요청 횟수·키 비노출을
검증합니다. 실제 공시를 복사한 fixture나 검증된 snapshot으로 표현하지 않습니다.
다음은 이 좁은 계약의 실제 응답 두 건을 확인하고 원문과 대조하는 단위입니다.
실제 응답의 계정 ID·통화·정정 공시 특성을 확인한 뒤 별도 단위에서 승인 UI에 연결합니다.

- [HTTPX 전송 계층](https://www.python-httpx.org/advanced/transports/): 모의 전송과 재시도 제어.

API 문서 확인은 실제 인증·응답 검증을 대신하지 않습니다. 사업보고서가 정정될 수 있고,
서로 다른 보고서의 당기값 비교는 하나의 최신 보고서가 재작성한 비교기간 수치와 다를 수 있습니다.
