# KOSIS 승인 조회 실제 확인

2026-09-16 로컬에서 실제 API와 참가자 화면을 연결해 확인했습니다. 확인 주체는 Codex이며
사람의 통계 해석 검토나 기사 사용 승인이 아닙니다. 기존 [자료 계약 확인 6회](KOSIS_EMPLOYMENT.md#자료-계약의-수동-확인-기록과-fixture)와
별도로, 이번 연결 확인은 최대 4회 예산 안에서 **자료 조회 2회**로 마쳤습니다.
Gemini·OpenDART는 추가 호출하지 않았습니다. 자동 테스트는 모두 모의 전송입니다.

## 실행 조건

- 로컬 API `127.0.0.1:8000`, Vite `127.0.0.1:5173`.
- 사용자 허용 범위에서 `.env`에 `KOSIS_ENABLED=true`를 추가하고 백엔드를 재시작했습니다.
  `LIVE_API_ENABLED=true`, `PUBLIC_DATA_MODE=live`와 기존 키를 백엔드에서 사용했습니다.
  키를 출력하거나 Git·브라우저·프론트엔드 설정에 넣지 않았습니다.
- 화면에서 ‘공식 실제 자료 · OpenDART / KOSIS’, ‘모의 규칙’을 선택했습니다.
  질문 해석의 실제 모델 호출과 실제 자료 조회를 독립적으로 확인했습니다.
- 질문: `전국 시·도 15-29세 청년 고용률 2020-2024년 연간 증감 폭 비교`.

## 참가자 흐름과 실제 응답

1. ‘질문 분석’ 후 대상·지표·기간·비교 기준·연령·주기를 확인했습니다. 이 단계에는
   자료·브리핑·사람 검토가 없고 KOSIS 요청도 없습니다.
2. 첫 ‘이 조건으로 조회’에서 API 한 번으로 17개 시도 × 5년 = 85개 셀을 받았습니다.
   승인 조건과 최종 근거 조건이 같고, 연간 원자료·출처·최종수정일·실제 조회 시각이
   표시됐습니다. 순위는 17개이며 검토는 0/4로 시작했습니다.
3. 출처 검토 항목을 체크한 뒤 비교 기준만 ‘증감률’로 바꿨습니다. 결과·비교·검토가
   숨겨지고 참가자 수정 표시와 재승인 안내가 나왔습니다.
4. 다시 승인하여 두 번째 API 요청을 실행했습니다. 직전 증감 폭과 이번 증감률,
   서로 다른 단위·순위가 표시되고 새 결과의 검토는 다시 0/4였습니다.

| 확인 | 첫 승인 | 두 번째 승인 |
|---|---|---|
| 비교 기준 | 증감 폭 | 증감률 |
| 변화 1위 | 강원특별자치도 | 전북특별자치도 |
| 시작 → 종료 공표값 | 40.8% → 48.1% | 31.5% → 38% |
| 계산 | 48.1 − 40.8 = 7.30%p | (38 − 31.5) / 31.5 × 100 = 20.63% |
| 조회 완료 시각(KST) | 2026-09-16 21:32:42 | 2026-09-16 21:33:08 |
| 자료 최종수정일 | 2026-06-29 | 2026-06-29 |

브리핑은 고용률 수준이나 정책 효과의 순위로 표현하지 않습니다. 일반 응답은 고정 모의
예시이며, 실제 자료와 계산 결과도 사람 검토 필요·기사 사용 승인 아님을 유지했습니다.
근거 패널의 기존 한국어 문체·색상·표 배치와 접을 수 있는 원자료 표시도 브라우저로 확인했습니다.

## 공식 통계표 화면 대조

근거의 [KOSIS 원표](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1DA7015S)를
열었습니다. 초기 화면은 최근 분기를 표시하므로 시점 설정에서 분기를 해제하고 연간
2020·2024년을 선택했습니다. `15 - 29세` 행의 `고용률 (%)` 열을 앱과 대조했습니다.

**17개 시도 × 두 연도 = 34개 시작·종료 공표값이 모두 수치상 일치**했습니다.
공식 표의 `38.0`, 앱의 정규화 값 `38` 같은 표시 차이는 수치 비교로 확인했습니다.
앱의 연간 원자료에는 공표 문자열을 별도로 보존합니다. 예시는 다음과 같습니다.

| 시도 | 2020 | 2024 |
|---|---|---|
| 서울특별시 | 46.6 | 51.2 |
| 경기도 | 43.1 | 49.5 |
| 강원특별자치도 | 40.8 | 48.1 |
| 전북특별자치도 | 31.5 | 38.0 |
| 제주특별자치도 | 41.6 | 42.1 |

공식 화면 전체 표의 갱신일은 2026-08-12로 표시됐지만 조회한 연간 셀의 API 최종수정일은
2026-06-29였습니다. 표 전체 갱신일·개별 자료 수정일·이번 조회 시각을 같은 의미로 쓰지 않습니다.
이번 화면 대조는 시작·종료 값 34개에 한정합니다. 중간 3년까지 85개 셀 전체를 공식 화면과
전수 대조하거나 표본오차·행정경계·인과 해석을 검증한 것은 아닙니다.

## 자동 검증과 제한

- 백엔드 458건, 프론트엔드 79건 통과. Ruff·TypeScript·Vite·Python 패키지 빌드 통과.
  패키지 인덱스 접근 없이 기존 캐시를 사용하는 `UV_OFFLINE=1 make check`로 실행했습니다.
- 새 모의 전송 검사는 비활성·키 누락·인증·한도·타임아웃·크기 제한·중복 JSON 키·로그
  비밀정보 비노출·전체 정규화 중단을 검사합니다. 공급자별 설정은 서로 독립적입니다.
- 승인 누락·범위 밖 조건은 외부 요청 전 거부하고, 수정 대상·기간·비교 기준을 보존하며
  실행 중 해석기를 호출하지 않는지 검사합니다. 누락·통계 부호는 부분 순위로 대체하지 않습니다.
- 화면 검사는 승인 전 숨김·재승인·공식 출처·모드/자료원 불일치 응답 거부·검토 초기화·
  실패 후 입력 유지·늦은 응답 무시와 기존 mock/OpenDART 회귀를 포함합니다.
- `git diff --check`와 Git 대상 파일의 비밀정보 검사를 수행했습니다. `.env`는 무시 대상입니다.
  기존 테스트 의존성의 deprecation 경고 2건은 남아 있습니다.

실제 오류·한도 초과를 만들기 위해 외부 호출을 반복하지 않았습니다. 오류 검증은 모의
전송으로 수행했습니다. 다른 연령·지표·표·지원 기간 밖 조회, Gemini 브리핑 생성,
캐시·운영 호출 제한·snapshot fallback·DB·인증·배포·30명 부하 시험은 이번 범위 밖입니다.
