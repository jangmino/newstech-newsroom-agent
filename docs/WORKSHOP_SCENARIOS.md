# 오류·모호성 실습 안내

M1의 마지막 mock 실습 단위입니다. ‘막히는 상황 체험’에서 기존 질문
‘최근 5년 동안 청년 고용이 가장 좋아진 지역은 어디인가?’를 사용합니다.
새 질문·공급자·외부 API·저장 기능은 추가하지 않습니다.
모든 숫자는 가상 자료이며, 실습 검토는 사실 검증 완료나 기사 사용 승인이 아닙니다.

## 참가자가 진행하는 세 장면

각 장면을 선택하면 이전 질문·결과·비교·검토가 초기화됩니다. 이후 참가자가 직접
‘질문 분석’을 누릅니다. 장면 선택과 ‘예시 조건 넣기’는 API를 호출하지 않으며,
조건 적용 후에도 ‘이 조건으로 조회’를 눌러야 자료·브리핑을 표시합니다.
예시 조건은 버튼 위에 미리 표시하고, 적용 후 입력란의 ‘수정됨’으로 확인합니다.

| 장면 | 확인할 문제 | 수정과 재승인 |
|---|---|---|
| 모호한 질문 | ‘최근’, ‘좋아졌다’, 청년 연령 등을 임의로 정하지 않아 조건이 비어 있음 | 직접 선택하거나 전국·고용률·2020-2024·증감 폭·15-29세·연간 예시를 넣은 뒤 승인 |
| 지원 범위 밖 기간 | 예시의 2019-2024는 가상 자료 지원 범위를 벗어나 조회 버튼이 비활성화됨 | 기간만 2020-2024로 고친 뒤 나머지 조건도 확인하고 승인 |
| 0 기준값과 누락값 | 전국·취업자 수·2020-2024·증감률·15-34세·연간을 승인하면 A는 0 기준값, C·D는 종료 값 누락으로 계산 불가 | 원자료 표와 경고를 읽고 기간만 2021-2023으로 수정, 직접 재승인하여 비교와 새 검토를 확인 |

세 번째 장면의 수정 버튼은 계산 불가 결과를 실제로 받은 뒤에만 나타납니다.
2021-2023년은 네 가상 지역 모두 계산 가능한 시작·종료 값을 갖습니다. 이는 **비교 범위를
바꾼 것**이며 2020-2024년의 누락값을 해결한 것이 아닙니다. 바뀐 기간이 원래 취재 질문에
적합한지 사람이 판단해야 합니다. 원래 기간으로 돌아가면 원래 계산 불가 상태가 유지됩니다.

조건 변경 후에는 이전 결과를 숨깁니다. 재승인 성공 후 직전 결과와 이번 결과를 각자의
조건·단위로 비교하며, 새 결과의 검토는 0/4부터 시작합니다. 조건 승인·계산 완료·실습
체크 완료 중 어느 것도 가상 자료를 실제 기사에 쓸 수 있다는 승인을 뜻하지 않습니다.

## 안내 상태와 오류 복구

- 현재 계획·입력값·요청 상태·계산 결과에서 다음 행동을 안내합니다. 별도의 완료 인증은 없습니다.
- 참가자는 예시를 적용한 뒤에도 모든 조건을 직접 수정할 수 있습니다. 자동 조회·자동 승인은 없습니다.
- 질문 입력·다른 예시 질문 선택은 안내를 닫습니다. 같은 질문 재분석은 안내를 유지하지만
  조건·결과·비교 기준·검토는 초기화합니다.
- 다른 장면 선택은 기존 결과와 비교 기준까지 초기화합니다. 요청 중 장면을 바꿔도
  늦게 도착한 이전 응답은 무시합니다.
- ‘안내 닫기’는 안내만 닫으며 현재 조건·결과·검토 체크를 유지합니다.
- 실제 요청 실패 시 입력을 유지하고 분석 또는 조회를 재시도하도록 안내합니다.
  실습 버튼으로 서버 장애를 주입하거나 성공을 꾸미지 않습니다.
- 새로고침하면 안내·조건·결과·검토가 모두 초기화됩니다. 서버나 브라우저 저장소에 기록하지 않습니다.

## 구현과 계약

`apps/web/src/workshopScenarios.ts`에 실습 설명과 조건을 정의하고,
`WorkshopGuide.tsx`가 현재 화면 상태에 맞는 안내를 표시합니다. `App.tsx`의 기존
조건 무효화·요청 버전 검사를 사용합니다. 예시 적용도 수동 편집과 동일한 승인을 요구합니다.

백엔드·프론트엔드 요청 및 응답 계약은 변경하지 않습니다. 기존 `/plan`, `/execute`를
사용하며, API의 `review_required`와 `/analyze` 호환 경로도 유지합니다.
가상 숫자와 계산 규칙은 [ADR 0003](decisions/0003-synthetic-mock-calculations.md),
전후 비교는 [조건 비교 문서](CONDITION_COMPARISON.md)를 따릅니다.

## 검증

`make test-web`은 자동 실행 차단, 조건 적용·명시적 승인, 기간 검증·수정, 누락값 안내,
기간 변경 후 결과 숨김·재승인·검토 초기화, 요청 실패·재시도, 장면 전환 중 늦은 응답,
자유 편집·질문 변경·재분석·안내 닫기를 검증합니다. 모든 요청은 모의 응답으로 대체합니다.
백엔드 테스트는 2021-2023년 계산과 승인 조건 반영, 원래 기간의 누락값 보존을 확인합니다.
최종 검증은 `make check`와 `git diff --check`입니다.

브라우저에서는 위 세 장면을 진행하고, 좁은 화면과 키보드로 조건 선택·승인·표 읽기가
가능한지 확인합니다. 실제 공급자의 장애·fallback·부하 시험은 M3의 별도 범위입니다.
