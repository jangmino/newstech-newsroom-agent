## 참가자 브라우저 확인

Chrome의 로컬 Vite → FastAPI 경로에서 다음을 확인했습니다.

1. ‘조회 자료: OpenDART 실제 자료’, ‘질문 해석 방식: 모의 규칙’을 선택했습니다.
2. `삼성전자 2022-2024년 연결 연간 매출액 증감률 비교`를 분석했습니다.
   지원 조건이 채워지고 자료·브리핑·검토는 표시되지 않았습니다.
3. 비교 기준을 ‘증감 폭’으로 수정했습니다. 수정 표시 후 별도로 승인했으며,
   실제 조회 결과는 **-1,360,457,000,000원**이었습니다. 승인 조건과 최종 조건이 일치했습니다.
4. 공시 금액·원문 링크·접수번호·조회 시각·원 단위·계산식과 실제 자료 표시를 확인했습니다.
   일반 응답은 고정 모의 예시로 구분했습니다.
5. 출처 검토 항목을 체크한 뒤 ‘증감률’로 바꾸자 결과와 검토가 숨겨졌습니다.
6. 재승인 후 결과 **-0.45%**, 직전 결과와의 조건 비교, 검토 **0/4 초기화**를 확인했습니다.
7. 실제 결과 화면을 시각적으로 확인했습니다. 확인한 데스크톱 창에서는 페이지 가로
   넘침이 없었고 자료 표·링크가 표시됐습니다. 모바일 실기기 검증은 별도로 수행하지 않았습니다.

두 승인 결과의 조회 시각은 각각 11:54:13, 11:54:32 UTC였습니다. 이후 자동 확인을 위해
추가 실제 조회하지 않았습니다. 위 값은 이번 확인 시점의 값이며 앱에 하드코딩하지 않았습니다.
