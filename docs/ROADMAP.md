## M2 — Live providers

계산 기초는 M1 비교 화면 다음에 작은 mock 수치 자료로 먼저 구현합니다. 이를 M1의
조건 변경에 따른 결과 비교에 사용한 뒤 실제 공급자를 연결합니다. 구현 순서는
[개발 하네스](CODEX_HARNESS.md#2-한-번에-하나의-제품-단위)를 따릅니다.

- [x] M2 준비: 기존 청년 고용 질문의 가상 수치·증감 폭/률·순위·단위·누락값 검증
- [x] M2 준비: 질문 구조화 어댑터·출력 계약·모호성·오류 검증 (mock)
- [x] Gemini 구조화 질문 계획 연결 코드·모의 전송 검증 (기본 비활성화)
- [x] Gemini 로컬 API 키·모델 접근과 두 질문의 최소 해석 확인 (모호/명확 각 2건, 실제 4회)
- [x] OpenDART 삼성전자 연간 연결 매출액 어댑터·정규화·모의 전송 검증
- [ ] OpenDART 두 연도 실제 응답과 공시 원문 대조
- [ ] OpenDART 기업·재무 시나리오
- [ ] KOSIS 청년고용 시나리오
- [ ] 실제 공급자 자료의 정규화·단위·누락값 검증
- [ ] 검증된 fixture

현재 위치는 **M1 참가자 흐름 완료 + M2 Gemini 실제 확인·OpenDART 어댑터 준비 완료**입니다.
공식 자료를 참가자 화면에 연결하지 않았으며 행사 운영 준비 완료를 뜻하지 않습니다.
실제 모델 확인의 범위와 한계는 [확인 기록](GEMINI_SMOKE_TEST.md)에 있습니다.
다음 최소 단위는 OpenDART 삼성전자 2022·2024년 연결 매출액의 실제 응답·원문 대조입니다.
자료원별 계약·검증이 준비될 때까지 OpenDART·KOSIS 자료는 계속 mock입니다.
