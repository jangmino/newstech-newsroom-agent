## M2 — Live providers

계산 기초는 M1 비교 화면 다음에 작은 mock 수치 자료로 먼저 구현합니다. 이를 M1의
조건 변경에 따른 결과 비교에 사용한 뒤 실제 공급자를 연결합니다. 구현 순서는
[개발 하네스](CODEX_HARNESS.md#2-한-번에-하나의-제품-단위)를 따릅니다.

- [x] M2 준비: 기존 청년 고용 질문의 가상 수치·증감 폭/률·순위·단위·누락값 검증
- [x] M2 준비: 질문 구조화 어댑터·출력 계약·모호성·오류 검증 (mock)
- [x] Gemini 구조화 질문 계획 연결 코드·모의 전송 검증 (기본 비활성화)
- [x] Gemini 로컬 API 키·모델 접근과 두 질문의 최소 해석 확인 (모호/명확 각 2건, 실제 4회)
- [x] OpenDART 삼성전자 연간 연결 매출액 어댑터·정규화·모의 전송 검증
- [x] OpenDART 두 연도 실제 응답과 공시 원문 대조
- [x] OpenDART 기업·재무 시나리오 (삼성전자 2022·2024 연결 매출액·증감 폭/률)
- [x] KOSIS 공식 통계표·차원·단위 계약 (15~29세 고용률, 17개 시도, 2020~2024년)
- [x] KOSIS 청년고용 시나리오 (승인 후 15~29세 고용률 조회·증감 폭/률·시도 순위·근거·검토)
- [x] 실제 공급자 자료의 정규화·단위·누락값 검증 (승인 실행에 적용, 자동 검증은 오프라인)
- [x] 검증된 fixture (OpenDART 원문 대조, KOSIS API 메타데이터·85개 셀 대조; 사람 검토 별도)

현재 위치는 **M1·한정된 M2 완료 + M3 운영 준비 진행 중**입니다.
OpenDART와 KOSIS 모두 실제 자료 선택·조건 승인 뒤에만 조회합니다. 자동 테스트는
계속 모의 전송만 사용합니다. [OpenDART 기록](OPENDART_SMOKE_TEST.md),
[KOSIS 기록](KOSIS_SMOKE_TEST.md)과 각 자료 계약에 지원 범위·확인 한계를 남깁니다.
다른 기업·지표·기간·연령까지 지원하는 것은 아니며 넓은 Gemini 품질 검증도 남아 있습니다.
공공자료의 프로세스 내부 캐시·동일 요청 합치기를 완료했습니다. 재사용 표시와 원래 조회
시각·기한을 유지하며, 다음은 공공자료 호출·동시 실행 제한입니다.

## M3 — Event readiness

- [x] 공공자료의 프로세스 내부 캐시·동일 요청 합치기·재사용 메타데이터
- [ ] 공공자료 호출·동시 실행 제한
- [ ] 접근코드
- [ ] 구조화 로그와 운영 상태
- [ ] stage 배포
- [ ] 30명 부하 시험
- [ ] 장애·snapshot fallback 리허설
- [ ] 운영자 가이드

Gemini에는 개발용 프로세스 내부 한도를 추가했습니다. 여러 인스턴스를 포함한 행사
전체의 제한·인스턴스 간 정책·부하 검증은 위 항목의 남은 범위입니다.
[캐시 검증](PUBLIC_DATA_CACHE.md)의 30개 동시 작업 검사는 행사 부하 시험을 대신하지 않습니다.
stage는 프론트엔드 정적 빌드와 FastAPI를 단일 Cloud Run 서비스로 제공하며, 기관/주최 측
프로젝트·자격증명과 Secret Manager를 사용합니다. 실제 배포·과금 활성화는 별도 승인 범위입니다.
