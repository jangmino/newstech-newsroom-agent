# KOSIS 청년 고용 자료 계약

2026-09-16에 공식 API의 통계표·항목·분류·단위와 작은 자료 범위를 확인했습니다.
이번 단계는 **자료 계약과 오프라인 정규화 검증**입니다. 참가자 화면의 KOSIS는 계속
mock이며 `/plan`, `/execute`, `/analyze`와 프론트엔드 타입은 바뀌지 않았습니다.
네트워크 조회·승인 UI 연결은 다음 단위입니다. [ADR 0007](decisions/0007-kosis-youth-employment-contract.md)을 따릅니다.

## 공식 통계표와 첫 지원 범위

자료원은 KOSIS의 국가데이터처 경제활동인구조사입니다.
[공식 통계표](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1DA7015S)와
[자료 API 안내](https://kosis.kr/openapi/devGuide/devGuide_0201List.do)를 확인했습니다.
아래 코드는 문서의 예제에서 추정하지 않고 이 표의 실제 메타데이터와 자료로 확인했습니다.

| 항목 | 확인한 계약 |
|---|---|
| 기관·표 | `101 / DT_1DA7015S`, 행정구역(시도)/연령별 경제활동인구 |
| 지표 | 항목 `T90`, 고용률, `%` (항목 메타데이터 단위 ID `14STD00018`) |
| 지역 | 분류 1 `A`, 아래 17개 시도 코드 |
| 연령 | 분류 2 `G`, 코드 `75`, API 명칭 `15 - 29세` |
| 성별 | 별도 성별 분류를 지정하지 않는 표의 공표값; 성별 세분 미지원 |
| 기간 | 2020~2024년 내 시작 연도 < 종료 연도, 그 사이의 모든 연간 값 |
| 주기 | 요청 `prdSe=Y`, 실제 자료 응답 `PRD_SE=A` |
| 값 | API `DT`의 문자열 보존, Decimal로 0~100 범위 검사 |
| 시각 | 응답을 받은 시각과 행의 `LST_CHN_DE`(자료 최종수정일)를 별도로 보관 |

확인 당시 연간 기간 목록은 2000~2025년이었습니다. 지원 기간은 기존 실습에 맞춰
2020~2024년으로 좁혔습니다. 이 표는 주석상 분기·연간 자료를 제공하지만 월·분기 조회는
이번 계약에 포함하지 않습니다. 실제 자료 행에는 `UNIT_ID`가 없어 `UNIT_NM=%`를 검사하고,
단위 ID는 별도로 확인한 항목 메타데이터에만 남깁니다.

| 코드 | 시도 | 코드 | 시도 |
|---|---|---|---|
| 11 | 서울특별시 | 21 | 부산광역시 |
| 22 | 대구광역시 | 23 | 인천광역시 |
| 24 | 광주광역시 | 25 | 대전광역시 |
| 26 | 울산광역시 | 29 | 세종특별자치시 |
| 31 | 경기도 | 32 | 강원특별자치도 |
| 33 | 충청북도 | 34 | 충청남도 |
| 35 | 전북특별자치도 | 36 | 전라남도 |
| 37 | 경상북도 | 38 | 경상남도 |
| 39 | 제주특별자치도 | | |

명칭은 확인 당시 API의 명칭입니다. 각 연도 당시 명칭이나 동일 행정경계를 보증하지 않습니다.
전체 메타데이터에는 전국 집계 `00`과 추가 집계 `12`도 있으므로 `ALL`이나 현재 분류의
말단 노드 자동 선택을 쓰지 않습니다. 전국 시·도는 위 17개, 수도권은 `11,23,31`,
비수도권은 나머지 14개를 **각각 비교**합니다. 권역 고용률을 단순 평균으로 만들지 않습니다.

## mock 조건과의 차이

| 기존 mock | 첫 실제 자료 계약 |
|---|---|
| 가상 지역 A~D | 명시한 공식 17개 시도 또는 수도권/비수도권 부분집합 |
| 15~29세·15~34세 | 15~29세만 확인; 15~34세 직접 분류 없음 |
| 고용률·취업자 수 | 고용률만 확인; 이 표의 항목 목록에 취업자 수 `T30` 없음 |
| 의도적으로 넣은 0·누락값 | 확인한 85개 셀은 모두 유효한 수치; 오류 테스트는 별도 변형 |

15~29세와 30~34세의 고용률을 평균내어 15~34세를 만들거나 고용률에서 취업자 수를
역산하지 않습니다. 다른 표 연결은 별도 계약 검토가 필요합니다. 이번 단계는 mock 선택지를
삭제하지 않습니다. 후속 실제 조회 화면에서는 이 차이를 한국어로 안내하고, 지원하지 않는
조건을 자동 교체하지 않고 참가자가 수정·승인하도록 해야 합니다.

## 내부 정규화 계약

`providers/kosis_employment.py`는 설정·파일·네트워크에 접근하지 않는 순수 모듈입니다.

- `EmploymentQuery`: 대상·지표·연령·시작/종료 연도를 명시적으로 받아 지원 범위를 검사합니다.
  비교 기준은 자료 선택을 바꾸지 않으므로 후속 오케스트레이터·계산 계층에서 검증합니다.
- `parameters`: 위 표·항목·연령·지역 코드와 연간 범위를 지정합니다. `smblChk=Y`로
  통계 부호가 숫자에 가려지지 않도록 요청합니다. 인증키는 포함하지 않습니다.
- `normalize_employment(payload, query, retrieved_at)`: 모든 요청 지역 × 연도의
  셀이 정확히 한 번씩 있어야 합니다. 응답 순서에 의존하지 않고 코드·명칭·주기·연도·
  단위·추가 분류 유무를 검사한 뒤 일정한 지역·연도 순서로 반환합니다.
- 결과는 원래 `DT`, 정규화한 숫자 문자열, 시도 코드/명칭, 연도, 단위, 최종수정일을
  보존합니다. 표/항목/연령 코드, 공개 출처 링크, 조회 조건·시각·주의사항도 남깁니다.
- 누락 행, 중복 행, 단위 불일치, 빈 값, 통계 부호 또는 0~100 범위 밖 값이면 전체를
  중단합니다. 통계 부호의 뜻을 추정해 0이나 임의의 수치로 바꾸지 않으며 부분 순위도 만들지 않습니다.
  숫자 `0`과 `0.0`은 유효한 값입니다. 오류는 고정 한국어 문장으로만 전달합니다.
- 자료의 공표 반올림을 유지합니다. 증감 폭은 `%p`, 증감률은 `%`로 구분하고 시작 값이
  0인 증감률은 계산 불가로 처리하는 연결 작업은 다음 단위입니다.

이 모듈은 아직 앱의 실행 경로에 연결되어 있지 않습니다. 기존 `providers/kosis.py`의
검색 골격도 미사용이며, 안전한 전송·명시적 활성화·오류 매핑을 갖추기 전에는 연결하지 않습니다.
공개 API 계약 변경이 없어 프론트엔드 타입 변경도 없습니다.

## 수동 확인 기록과 fixture

로컬 백엔드 설정의 키를 사용해 사전 안내한 10회 이내에서 **총 6회** 호출했습니다.
키·인증 URL·민감한 원본 오류는 출력하거나 저장하지 않았습니다. `.env` 변경은 없습니다.

| 호출 | 결과 |
|---|---|
| 통계 검색 1회 | 표·기관·조사명 확인 |
| `getMeta / ITM` 1회 | 항목·지역·연령 메타데이터 47행 |
| `getMeta / PRD` 1회 | 분기·연간 기간 목록 확인 |
| `getMeta / UNIT` 1회 | 오류 `30`(자료 없음); 재시도하지 않음 |
| `getMeta / CMMT` 1회 | 주석 8행(빈 주석 포함) |
| 자료 조회 1회 | 17개 시도 × 5년 = 85개 셀, 모두 `%`, 주기 `A` |

단위 조회의 오류를 무시하고 성공으로 처리한 것이 아니라, 항목 메타데이터의 `%`와
85개 자료 행의 `%`를 독립적으로 대조했습니다. 확인 시 모든 행의 최종수정일은
`2026-06-29`였고 응답 보관 시각은 `2026-09-16T12:11:07.142863+00:00`입니다.
예를 들어 서울의 2020년 `46.6`, 2024년 `51.2`, 제주의 2024년 `42.1`을
발췌·정규화 전후에 그대로 유지하는지 테스트합니다. 이는 고용 개선 원인이나 통계적
유의성을 확인한 결과가 아닙니다.

[공개 fixture](../fixtures/public-data/kosis-youth-employment-2020-2024.json)는
자료의 한글 식별 필드·수치·최종수정일을 선택한 발췌입니다. 85개 셀과 수치 문자열은
바꾸지 않았습니다. 영문 필드를 제외한 항목 메타데이터 전체, 연간 기간 목록, 주석,
출처·조건·보관 시각·검사 주체(Codex)·검증 한계를 함께 기록합니다.
별도 통계표 화면과의 전수 대조나 사람의 통계 해석 검토를 마친 자료로 표시하지 않습니다.
런타임·fallback에서는 읽지 않습니다.

KOSIS [공유서비스 FAQ](https://kosis.kr/openapi/community/community_0401List.do)는
출처 표시를 전제로 통계 재이용을 안내하며, 국제·북한 통계의 예외도 설명합니다.
이 fixture는 국내 경제활동인구조사의 공개 통계로 출처와 조회일을 남겼습니다.
자료 개정 가능성이 있으므로 향후 갱신할 때도 같은 조건·단위·이용조건을 다시 확인합니다.

주석에는 2017년부터 충남·세종 분리로 이전 자료와 시계열 단절이 있다는 안내,
소급 인구 개정, 군인 등 조사대상 제외가 있습니다. 현재 기간은 그 이후지만 다른 경계
변경까지 해결됐다고 간주하지 않습니다. 표본오차·지역 정의·자료 개정과 비교 가능성은
최종 화면의 주의사항과 사람 검토에 남겨야 합니다.

## 검증과 다음 단위

`tests/test_kosis_employment.py`는 공식 발췌를 이용해 전체 셀·부분집합·기간·출처 보존을
검사하고, 변형한 오류 자료로 잘못된 표·연령·항목·지역·주기·단위, 누락·중복·통계 부호·
비정상 수치·시각을 검사합니다. 자동 테스트는 `.env`와 실제 네트워크를 사용하지 않습니다.

2026-09-16 검증 결과: 이 모듈의 테스트 77건, 전체 백엔드 364건·프론트엔드 68건 통과.
`make check`의 온라인 패키지 빌드는 제한된 네트워크에서 의존성 조회에 실패했으나,
기존 캐시를 사용한 `UV_OFFLINE=1 make check`로 lint·테스트·타입 검사·웹/패키지 빌드가
모두 통과했습니다. 기존 테스트 의존성의 deprecation 경고 2건은 남아 있습니다.
`git diff --check`와 추적/추가 파일의 비밀정보 검사도 통과했습니다.

다음 단위는 **KOSIS 승인 후 실제 조회 흐름**입니다. 별도 서버 활성화와 안전한 전송,
명시적 참가자 선택, 승인 조건 검증, 순위 계산·근거·브리핑·검토 UI를 연결하고 실제 화면을
소규모로 확인합니다. 이번에 확인한 범위로 한정하면 이들을 한 구현 단위로 진행할 수 있습니다.
기존 `/analyze`의 mock 호환성, 실패 시 자동 대체 금지, 조건 변경 시 결과·검토 초기화는 유지합니다.
Gemini 브리핑 생성, 취업자 수·15~34세·다른 통계표, M3 운영 기능은 포함하지 않습니다.
