# 조건 변경 전후 비교 (M1 mock · M2 OpenDART)

같은 질문에서 조건을 바꿨을 때 결과가 어떻게 달라지는지 확인하는 실습입니다.
mock에서는 각각 승인된 조건으로 만든 모의 결과를 비교합니다. 가상 수치는 실제 취재
근거가 아닙니다. OpenDART live에서는 각 승인 때 조회한 공시와 계산 결과를 비교합니다.

## 참가자 흐름

1. 질문을 분석하고 조건을 승인합니다. 첫 결과에는 전후 비교가 없습니다.
2. 질문은 그대로 두고 대상·지표·기간·비교 기준·추가 조건 중 하나를 수정합니다.
   결과와 검토 체크가 화면에서 사라집니다.
3. ‘이 조건으로 조회’를 눌러 새 결과가 도착하면 ‘조건 변경 전후 비교’가 나타납니다.
4. 바뀐 조건의 ‘변경’ 표시와 이전·이번 브리핑, 자료원·단위·계산식·시각·한계를 확인합니다.
5. 가상 지역별 표에서 입력값·변화값·순위를 나란히 확인합니다. 이번 결과의 검토는
   아래의 체크리스트에서 새로 시작합니다. 과거 체크는 이어받지 않습니다.

청년 고용의 전국 시·도·고용률·2020-2024·15-29세 조건에서 증감 폭을 먼저 승인하면
가상 지역 B가 9.00 %p로 1위입니다. 비교 기준만 증감률로 바꾸고 재승인하면 C가
23.33%로 1위입니다. 같은 원자료에서도 비교 기준에 따라 순위가 달라짐을 볼 수 있습니다.
기업 실적 mock은 숫자가 없어 조건·조회 설계만 비교합니다. OpenDART live는 증감 폭/률을
바꾸어 원/% 결과를 각각 표시하며 두 값의 차이를 새로 계산하지 않습니다.

## 비교와 초기화 규칙

| 상황 | 표시와 비교 기준 |
|---|---|
| 최초 승인 성공 | 결과만 표시, 전후 비교 없음 |
| 조건 편집·재조회 중 | 결과·비교·검토 표시를 숨김, 직전 성공 결과 한 건만 메모리에 유지 |
| 변경한 조건으로 승인 성공 | 직전 성공 결과 ↔ 이번 결과, 검토 0/4부터 시작 |
| 세 번째 이후 승인 성공 | 가장 최근 두 성공 결과만 비교 |
| 동일 조건 재조회 / 수정 후 원래대로 복원 | 조건 차이를 만들지 않고 이번 결과만 표시, 검토 초기화 |
| 요청 실패 | 결과를 표시하지 않음, 직전 성공 결과를 비교 기준으로 유지하여 재시도 가능 |
| 늦게 도착한 이전 응답 | 결과와 비교 기준 모두 갱신하지 않음 |
| 질문 수정·예시 선택·해석 방식 변경·다시 분석·새로고침 | 결과·비교 기준·검토 체크 모두 초기화 |

승인 조건은 자료원·대상·지표·기간·비교 기준과 필터 값으로 비교합니다. 요청 ID,
생성 시각, 자료원 선택 이유, 필터 키 나열 순서는 조건 변경이 아닙니다.
질문·자료원·자료 모드가 다른 응답은 섞어 비교하지 않습니다. 자료 모드 변경은
계획·결과·비교 기준·검토를 모두 초기화합니다.

## 수치 해석

- 각 결과의 입력값·단위·변화값·순위를 그대로 표시합니다. 두 변화값의 차이를 별도로
  계산하거나 프론트엔드에서 순위를 다시 매기지 않습니다.
- 순위는 각각의 조회 대상 안에서 정한 값입니다. 대상·연령·기간·지표·단위 등이 달라지면
  숫자를 그대로 대소 비교할 수 없고, 여러 조건을 바꾸면 원인을 하나로 단정할 수 없습니다.
- 양쪽 지역의 합집합을 보여줍니다. 한쪽에만 있는 지역의 반대쪽은 ‘조회 대상에 포함되지 않음’입니다.
- 입력값 누락과 0 기준값은 ‘계산 불가 · 순위 없음’과 이유를 유지합니다. 누락을 0으로 바꾸지 않습니다.
- 동률·반올림 전 순위·일부 지역만 계산한 경고를 유지하며, 모두 계산 불가여도 1위를 만들지 않습니다.

## 구현·검증 범위

`App`의 메모리와 `ConditionComparison`만 사용하며 DB·localStorage·sessionStorage나
조회 이력을 위한 서버 API는 없습니다. OpenDART 결과는 `financial_calculation`을 사용하며
`/analyze` 호환 계약을 유지합니다.
이전 승인 결과 보관은 현재 질문의 화면 비교용이며, 참가자 기록이나 감사 증명이 아닙니다.

`make test-web`은 승인 전·편집·로딩·오류 시 숨김, 조건별 변경 표시, 직전 성공 기준,
동일 조건·질문 변경·재분석·앱 재시작 초기화, 실패·늦은 응답 처리, 검토 초기화,
단위·입력값·동률·계산 불가·대상 제외를 검사합니다. 실제 요청 없이 모의 응답을 사용합니다.
브라우저에서는 위의 B→C 순위 변경, 기업 실적 조건 비교, 모바일 표 스크롤을 확인합니다.
