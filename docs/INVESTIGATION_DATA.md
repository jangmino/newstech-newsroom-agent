# 다섯 조사 사례의 공식 자료 구성

기준일: 2026-10-05. 가상 수치는 포함하지 않았다. 공개 API 응답과 공식 사업보고서에서
필요한 셀·표만 추출했다. 참가자가 조사 계획을 승인한 뒤에만 수치를 읽고 계산한다.
원자료 수집 시각과 새 Gemini 브리핑 생성 시각은 별도로 표시한다.

## 제공 범위와 방식

| 사례 | 공식 자료와 범위 | 참가자 조회 방식 | 핵심 경계 |
|---|---|---|---|
| A 출생 | KOSIS 101/DT_1B8000G, 전국·17시도, 2004-01~2026-07 원자료 | 실제 조회 또는 공식 저장 원자료 재계산 | 기본 분석 2005-01 이후. 앞 12개월은 전년 동월 비교용. '역대 최장'이 아닌 선택 기간 내 최장 |
| B 청년 이동 | DT_1B26001 전입·전출·순이동, DT_1B040M5_1 주민등록연앙인구, DT_1B26003 시도 간 OD; 2023~2025, 20~34세 | 실제 조회 또는 공식 저장 원자료 재계산 | 전국 시도 비교·선택 시도 목적지. 시군 상세는 경북만 검증. 목적지와 순유출은 다른 통계 |
| C 물가 | DT_1J22001 전국 품목별 지수와 공식 WGT; 2025-09/2026-09 | 실제 조회 또는 공식 저장 원자료 재계산 | 2020 기준 지수, 2022 가중치. 말단 458품목 가중치 합계 1,000. 공식 기여도가 아닌 고정 가중치 근사 |
| D 보수 | NAVER·카카오 2025 사업보고서 직원 합계, 대표이사 직위·개인별 보수 API와 원문 구성표 | 원문 대조한 공식 저장 원자료 재계산 | 연결그룹 전체가 아닌 공시 법인. 임의 회사·연도 확장은 하지 않음 |
| E 성장 구조 | NAVER·카카오 2021~2025 사업보고서 10건과 각 연도 연결 손익 API | 원문 대조한 공식 저장 원자료 재계산 | 양사의 서로 다른 사업 분류를 보존. 상세 사항 아래 참조 |

공식 저장 **원자료**는 승인할 때마다 코드 계산·새 AI 브리핑의 입력이 된다. 기존 장애용
공식 저장 **결과**(`snapshot`)는 같은 고정 조건의 자료와 사전 생성 브리핑을 그대로 재생한다.
두 방식은 다르다. 2026-10-06 [ADR 0022](decisions/0022-workshop-81-capacity.md)에 따라
새 다섯 사례의 대표 질문·고정 조건에 장애용 사전 생성 브리핑·일반 응답을 추가했다.
이는 Gemini 자체 장애 때도 새 모델 호출 없이 재생할 수 있는 별도 snapshot이다.
공식 저장 원자료 모드에서 새 브리핑까지 오프라인 제공한다고 약속하지 않는다.
조회·계산 근거는 브리핑 실패 시에도 남으며 기존 행사 저장 결과는 계속 사용할 수 있다.

## E: 무엇을 준비했나

1. 회사 2곳 × 사업연도 5개 = 사업보고서 10건. 정정된 보고서는 정정 후 표를 선택했다.
2. 각 보고서의 사업별 매출 당기액·같은 표의 전기 비교액·당기 합계를 백만원으로 보관했다.
   NAVER는 서치플랫폼·커머스·핀테크·콘텐츠·클라우드 또는 엔터프라이즈 5분류,
   카카오는 플랫폼·콘텐츠 2분류다. 총 35개 회사·연도·사업 행이다.
3. 같은 접수번호의 연간 연결 매출액·영업이익을 원 단위로 보관하고 사업 매출 합계와 대조했다.
4. 보고서 제목·접수번호·원문 URL·원문 XML SHA-256·추출 표 순번·표 전체 소규모 발췌·수집 시각을 남겼다.
5. 참가자 승인 뒤 사업 비중, 같은 보고서 전기 대비 증가액·비중 변화, 영업이익률을 계산한다.
   회사별 구성표·증가분 표·연결 실적표와 최근 연도 매출 비중 막대를 보여준다.

원문 위치는 `II. 사업의 내용 / 주요제품 및 서비스 또는 매출 및 수주상황`이다.
원문 해시는 `business_mix.json`의 `sources[].document_sha256`에서 확인한다.

정정·비교 기준 검증:

- 카카오 2021 정정 문서의 표 7에는 정정 전 매출이 남아 있다. 표 9의 정정 후 합계
  **5,910,513백만원**을 선택했다. 정정 전 **6,136,669백만원**과 혼동하지 않는다.
- 카카오 2021/2022 손익의 `ifrs-full_GrossProfit`은 해당 보고서에서 계정명이 `영업수익`이다.
  이 두 보고서에만 적용한 명시적 매핑이며 다른 회사의 매출총이익을 매출로 바꾸지 않는다.
- NAVER 2022 서치플랫폼 전기는 같은 보고서의 **3,307,835백만원**이다.
  2021 보고서 당기 **3,290,489백만원**과 다르므로 연간 증가액은 전자를 사용한다.
- 사업 분류 변경·중단영업·정정 전후의 기준 차이를 전 기간 소급 통일하지 않았다.
  클라우드와 엔터프라이즈를 자동 합치거나 양사 사업을 동등한 범주로 간주하지 않는다.
  전체 5년 CAGR·정밀 인과분해·제품 단위 원인 분석은 제공하지 않는다.
- 사업 합계와 재무 API 매출은 백만원 반올림 1백만원 이내로 대조했다.

## D: 보수 분모와 구성

2025 보고서는 위 E와 공유한다. NAVER 직원 표 2261·보수 구성 표 2282, 카카오 직원 표
2444·보수 구성 표 2463을 사용했다. NAVER 최수연 3,029백만원 / 직원 공식 합계 평균
146백만원 = 약 20.75배, 카카오 정신아 1,361백만원 / 109백만원 = 약 12.49배다.
남녀 평균을 단순 평균하거나 최고 보수자를 현 대표이사로 대신하지 않는다.
지급 주식 보상이 상여에 포함되면 중복 가산하지 않으며 미행사·미지급 보상은 더하지 않는다.
`-`는 원문 기호 그대로 보존한다. 평균 산정 방식·월별 인원·반올림의 차이는 원문 주석에 남겼다.

## 통계 결합·계산 경계

B의 이동 표와 연앙인구 표는 같은 지역도 코드 체계가 다르다. 동일 광역/기초 수준의 검증된
유일 지역명으로 결합한다. 포항시 인구와 남구·북구를 중복 합산하지 않는다. 2023년 군위군
편입이 포함된 경북·대구·군위의 인구 대비 비교는 제외하고 이유를 표시한다.
연평균 순이동률은 `기간 합계 순이동 / 기간 합계 연앙인구 × 100`이다.

C 근사 기여도는 `100 × 품목 가중치 × (종료 지수 - 시작 지수) / Σ(가중치 × 시작 지수)`다.
공식 총지수 상승률과 근사 합계의 차이도 표시한다. 지수 연결·가중치 기준 차이 때문에 공식
기여도와 같다고 주장하지 않는다. 말단 품목 일부가 누락되면 전체 순위 계산을 중단한다.

## 저장·재현

위치: `apps/api/src/newsroom_agent/investigation_data/`. `manifest.json`은 자료 파일 10개의
SHA-256을 고정한다. 런타임과 테스트 모두 해시를 확인한다. 원문 ZIP/XML 전체, 키가 있는
요청 URL, `.env`는 Git에 넣지 않는다. 공개 자료만 포함한 검증 발췌를 패키지에 포함한다.

수집은 승인된 수동 작업이다. 테스트·빌드·아래 추출 스크립트는 공급자를 호출하지 않는다.
원자료 수집 파일의 형식은 `{at, parameters, data}`이며 `parameters`에는 키를 넣지 않는다.
KOSIS 파일 이름은 `births-200401`, `births-201201`, `births-recent`, `migration`,
`population-correct`, `od`, `cpi-202509`, `cpi-202603`과 각 `*-meta`, `cpi-weights`다.
회사별 입력은 `{naver,kakao}-reports`, `-finance-{2021..2025}`, `-pay`, `-executives` 및
`{company}-{receipt}.xml`이다. 상세 입력과 표 선택 규칙은 아래 두 스크립트에 고정되어 있다.

```bash
python3 scripts/extract_investigation_tables.py .cache/investigation
python3 scripts/build_investigation_archive.py \
  --input .cache/investigation --output .cache/investigation/rebuilt
```

재수집 시 접수번호·분류·가중치·구간을 다시 대조하고 새 버전·manifest로 갱신한다.
추출 표 순번만 믿고 새 보고서를 자동 승인하지 않는다. 현재 데이터는 2026-10-05 검증본이다.
