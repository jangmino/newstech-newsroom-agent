# 가상 수치 계산 실습

이 자료는 **직접 만든 가상 지역·가상 숫자이며 공식 통계가 아닙니다**.
KOSIS에서 가져온 응답이나 장애 시 대신 제공할 공식 snapshot이 아닙니다.
실제 지역의 고용 상황·정책 효과를 설명하거나 기사에 사용할 수 없습니다.

실행 자료는 백엔드 패키지의
[`mock_employment.py`](../../apps/api/src/newsroom_agent/providers/mock_employment.py)에
`synthetic-employment-v1`로 보관합니다. 기간은 2020~2024년, 가상 지역은 A~D입니다.
기존 대상 선택값을 유지하되 전국은 A~D, 수도권은 A·B, 비수도권은 C·D를 뜻합니다.
고용률(%)·취업자 수(천 명), 15-29세·15-34세는 각각 별도 실습용 시계열입니다.

## 브라우저에서 확인하기

1. 청년 고용 예시 질문을 분석합니다. 자료와 결과가 아직 없는지 확인합니다.
2. 전국 시·도, 고용률, 2020-2024, 증감 폭, 15-29세를 선택하고 ‘이 조건으로 조회’를 누릅니다.
3. 표에서 B는 50→59, 9.00 %p로 1위입니다. A는 40→48, C는 30→37입니다.
4. 비교 기준을 증감률로 바꾸면 이전 결과가 사라집니다. 다시 승인하면 C가 23.33%로
   1위, A가 20.00%로 2위, B가 18.00%로 3위입니다. 계산 기준이 결론에 영향을 줍니다.
5. 15-34세 고용률의 증감 폭은 B·C가 공동 2위이고 D는 -3.00 %p입니다.
   동률·감소값도 그대로 표시합니다.
6. 15-34세 취업자 수의 증감률로 바꿉니다. A는 시작 값 0으로 계산 불가,
   C·D는 종료 값 누락으로 계산 불가입니다. B만 순위가 있고 일부 지역만 비교했다는
   경고가 나옵니다. 누락을 0으로 채우지 않습니다.
7. 같은 조건에서 비수도권을 고르면 모든 행이 계산 불가이며 1위를 제시하지 않습니다.
8. 기간을 2019-2024로 바꾸면 한국어 안내와 함께 승인을 막습니다. 다른 기간으로
   자동 대체하지 않습니다.

화면의 ‘막히는 상황 체험’은 이 규칙을 기존 청년 고용 질문으로 안내합니다.
‘0 기준값과 누락값’ 장면에서 전국·15-34세·취업자 수·증감률을 승인한 뒤 기간만
2021-2023으로 바꾸고 재승인하면 네 지역 모두 계산 가능합니다. A의 시작·종료 값은
10→14천 명, 증감률은 40.00%입니다. 비교 범위가 달라진 것이며 원래 2020-2024년
누락값을 채운 것이 아닙니다. [단계별 안내](../../docs/WORKSHOP_SCENARIOS.md)를 참고하십시오.

모든 단계에서 승인된 조건, 단위, 계산식, 가상 자료 계산 시각, 한계, 사람 검토 필요
상태를 확인합니다. 계산 완료는 실제 자료의 검증 완료를 뜻하지 않습니다.

계산 규칙과 제외 범위는 [ADR 0003](../../docs/decisions/0003-synthetic-mock-calculations.md),
요청·응답 계약은 [API 문서](../../apps/api/README.md)에 있습니다.
